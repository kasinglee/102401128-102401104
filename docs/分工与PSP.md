# HW4 结对分工与 PSP 预估

记录时间：2026-09-29，开始 HW4 编码前。以下为**建议分工和预估**，须与队友核对；实际耗时、完成情况和结对评价在工作发生后记录，不能预填。

## 实现目标与范围

- 交付 PC 端网页，测试人员下载全部文件后用 Google Chrome 打开 `index.html` 即可使用核心功能。
- 核心路径：发布寻物或招领 → 浏览或按关键词搜索 → 查看详情与联系方式 → 发布者在“我的发布”改为“已找回”或“已归还” → 公共页面看到更新后的状态。
- 先完成浏览、发布、搜索、详情、状态更新及异常提示，再决定是否加入类别/地点筛选、一键复制联系方式等附加特点。
- 不把原型里的单人会话演示误写成真实身份验证；程序设计时明确数据保存和发布者的判定规则，并写进 README。

## 交付顺序与提交节点

1. 仓库和基础目录、数据字段与接口约定。
2. 发布、表单校验、数据保存；完成后提交。
3. 首页浏览、搜索、无结果；完成后提交并发起或更新 PR。
4. 详情、联系方式、“我的发布”和状态更新；各功能完成后提交。
5. 合并后在 Chrome 走查正常与异常路径，运行单元测试并修复问题；再整理 README 和博客证据。
