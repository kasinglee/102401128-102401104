## 当前如何运行

下载或克隆整个仓库，在 **Google Chrome** 中直接打开根目录的 `index.html`，无需安装依赖或启动服务器。首次打开会显示三条虚构演示记录。下面每一步都可以照着复现。

### 1. 浏览与类型切换（第一阶段）

首页展示“共 N 条”，点“全部 / 寻物 / 招领”切换分类；进行中的信息排在已结束记录之前，已结束记录仍保留在列表里并显示状态标签。

### 2. 搜索（第二阶段）

1. 搜索框直接放在首页信息列表上方，不需要进入二级搜索页。
2. 输入关键词后点“搜索”或按 **Enter**，下方卡片会在首页原地更新；查询前会去掉首尾空格。
3. 搜索范围是**物品名称、补充描述、地点**三项，并可继续叠加“全部 / 寻物 / 招领”类型筛选。输入“耳机”能命中“黑色无线耳机”，输入“东3”能命中两个东3地点的记录。
4. 搜索后会显示当前关键词、结果数量和“清除搜索”按钮；输入不存在的词会给出明确的无结果说明。关键词为空时恢复显示全部信息。
5. 从筛选结果点进详情后，点详情左上角返回会回到首页，并保留关键词与类型筛选结果。

### 3. 查看详情与联系方式（第二阶段）

1. 在首页筛选结果里点任意卡片进入详情。详情展示物品类型、当前状态、名称、地点、发生日期时间、补充描述、发布时间，以及发布者上传的图片（没上传时显示占位图标）。
2. 详情用物品 ID 从同一条数据里取，列表和详情不会出现两套内容；物品找不到（ID 不存在）时会给出“没有找到这条信息”和返回首页的入口。
3. **联系方式默认折叠**。点“查看联系方式”才显示该条的 QQ / 校内账号与“联系前请先核对物品特征”的提示，按钮文案变为“收起联系方式”，箭头同时翻转；再点一次收起。页面不实现即时聊天，也不展示姓名、卡号等真实资料。
4. 展开后可点“复制联系方式”。若浏览器不允许访问剪贴板，程序会退回另一种复制方式；两种方式都不可用时，会选中联系方式并提示按 `Ctrl+C` 手动复制，**不会谎报复制成功**。
5. 详情左上角返回会回到进入详情前的页面：首页进来回首页并保留筛选条件，“我的发布”进来回“我的发布”；右上角“首页”按钮则直接回首页。
6. 状态被更新后再次打开详情会显示最新状态，已结束的记录仍然可以查看。

### 4. 发布（第一阶段，保持原样）

点导航“发布”或首页“发布一条信息”，选择“我在寻物 / 我来招领”，填写物品名称、地点、发生日期时间、补充描述（选填）、图片（选填，JPG/PNG/WebP，单张 ≤ 700 KB）和 QQ / 校内账号。必填项缺失或发生时间晚于现在会标红并阻止提交；提交成功后回到首页，新记录出现在列表里。

### 5. “我的发布”与状态维护（第二阶段）

1. 点导航“我的”进入“我的发布”。这里**只显示本浏览器新发布的记录**，预设演示记录的 `ownerId` 是 `demo`，不会混进来；没有记录时显示空状态与“去发布”按钮。
2. 每条进行中的记录下方有一个按钮：寻物显示“**标记已找回**”，招领显示“**标记已归还**”。点它调用 `store.finish(id)`，成功后会提示“「物品名」状态已更新为「已找回 / 已归还」，首页与搜索会同步显示”。
3. 权限不足或记录已结束时，页面显示失败原因（例如对演示记录操作会提示“只能修改自己发布的信息”），而不是静默失败。
4. 更新后该页卡片、首页列表、搜索结果和详情页显示的是**同一个**新状态。已结束的记录会保留并标注“已结束（…），不再提供重复结束按钮”，程序不删除任何记录。
5. “我的发布”里的卡片同样可以点进详情，返回时回到“我的发布”。

### 6. 刷新与持久化

刷新页面后，新发布的记录和新状态仍然存在，说明它们确实写进了 `localStorage`。

## 数据与限制

- 数据保存在**当前浏览器**的 `localStorage`（键名 `shijian.hw4.v1`）。更换电脑、更换浏览器或清除站点数据后，新增信息与状态不会同步，也不会出现在别人那里。
- 程序只能区分“**本浏览器**发布的记录”（`ownerId` 是本浏览器生成的 `clientId`），不能验证真实身份，也不是跨设备共享的多人平台。
- 图片以 data URL 形式一并存进 `localStorage`，因此单张限制 700 KB；浏览器存储空间或权限不足时会给出保存失败提示，不会假装保存成功。
- 演示记录与联系方式均为虚构数据。请勿在公开信息里填写手机号、证件号码等敏感资料。
