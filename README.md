## 当前如何运行

下载或克隆整个仓库，在 Google Chrome 中直接打开根目录的 `index.html`，无需安装依赖或启动服务器。当前可切换首页的“全部 / 寻物 / 招领”，点击“发布”填写并提交，返回首页查看新信息；点卡片可进入空白详情页并返回，点“我的”可进入空白“我的发布”页。刷新页面后，新信息仍保存在**当前浏览器**的 `localStorage` 中。更换电脑、浏览器或清除站点数据后，新增信息不会同步；首次打开会显示三条虚构演示记录。图片可选，单张限 700 KB；浏览器存储空间不足时会给出保存失败提示。

网页使用普通脚本而非 ES module，便于从本地 HTML 直接加载。后续页面应复用 `LostFoundStorage.createStore()`，接口见[接口约定](docs/接口约定.md)。第二阶段完成后，此处需补全搜索、详情、状态维护和单元测试的操作步骤。
